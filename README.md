# Account Security Lab

A classroom lesson for Mr. Makedon's class about protecting accounts, recognizing phishing, and getting help after a mistake.

- `index.html`: a clearly labeled message simulation with a decision activity and a warning-sign discussion.
- `lesson.html`: account security guidance and a six-question quiz with explanations and a retry option.

Suggested lesson: spend 5 minutes discussing the simulation, 10 minutes on the account security habits, and 5 minutes on the quiz and exit ticket. Students should use only the fictional examples here, never real passwords, recovery codes, or account details. Follow school guidance when setting up security features on school-managed accounts.

Both pages are self-contained static HTML with inline CSS and JavaScript. They use no external fonts, scripts, analytics, cookies, or browser storage. Activity responses and quiz scores stay in page memory and disappear on reload; nothing is submitted or collected. Reading content and the warning-sign reveal work without JavaScript; interactive feedback and quiz grading require JavaScript.

The existing `index.html` and `lesson.html` paths and link destinations are preserved for the classroom whitelist. GitHub Pages continues to publish from the root of `main`; no hosting or domain change is required.

Content references: CISA's Secure Our World guidance on strong passwords, MFA, and recognizing phishing; FIDO Alliance's passkey guidance. No additional external destinations are needed to use the lesson.
